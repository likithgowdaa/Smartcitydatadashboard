## 🆘 If Something's Wrong

### "Demo Mode" Won't Go Away?
```
1. Check API keys spelling is EXACT
2. Wait 30 seconds
3. Hard refresh: Ctrl+Shift+R
```

### Error Loading Data?
```
1. Press F12 → Check Console
2. Verify API keys are set
3. Try simple city: "Delhi"
```

### AI Not Responding?
```
1. Check OPENAI_API_KEY is correct
2. Verify OpenAI account has credits
3. Try simple query: "Hello"
```
