## 🎯 **PRIORITY SYSTEM EXPLAINED**

### **How Search Results Are Ranked:**

```
┌─────────────────────────────────────────────────────────────┐
│                   SEARCH ALGORITHM                          │
└─────────────────────────────────────────────────────────────┘

Step 1: Calculate Base Score
├─> Exact match:          +1000 points
├─> Starts with query:    +500 points
├─> Contains query:       +200 points
└─> State contains query: +100 points

Step 2: Add Priority Bonus
├─> Priority 0.5 (Bangalore): +100 points
├─> Priority 1 (Karnataka):   +50 points
├─> Priority 2 (India):       +20 points
└─> Priority 3 (World):       +10 points

Step 3: Sort & Return
├─> Sort by total score (highest first)
├─> Remove duplicates
└─> Return top 10 results

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

EXAMPLE: Search "bangalore"
├─> "Bangalore, Karnataka" → 1000 + 50 = 1050 (1st)
├─> "Bengaluru, Karnataka" → 1000 + 50 = 1050 (2nd)
└─> "Bannerghatta, Bangalore" → 500 + 100 = 600 (3rd)
```
