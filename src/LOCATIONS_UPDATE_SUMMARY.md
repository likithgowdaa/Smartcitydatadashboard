## 🎯 Priority System Explained

### How Search Results Are Ranked:

```
Priority 0.5 (HIGHEST) - Bangalore Areas
└─> Examples: Hebbal, Koramangala, Whitefield
    └─> Score Bonus: +100 points

Priority 1 (HIGH) - Karnataka Cities
└─> Examples: Mysore, Mangalore, Hubli
    └─> Score Bonus: +50 points

Priority 2 (MEDIUM) - Indian Cities
└─> Examples: Delhi, Mumbai, Chennai
    └─> Score Bonus: +20 points

Priority 3 (NORMAL) - World Cities
└─> Examples: London, Tokyo, New York
    └─> Score Bonus: +10 points
```

### Search Scoring System:
```
Exact match:          +1000 points
Starts with query:    +500 points
Contains query:       +200 points
State contains query: +100 points
+ Priority bonus      +10 to +100 points

Results sorted by total score (highest first)
```

### Search Algorithm:
```javascript
1. Calculate match score:
   - Exact match: +1000
   - Starts with: +500
   - Contains: +200
   
2. Add priority bonus:
   - Bangalore: +100
   - Karnataka: +50
   - India: +20
   - World: +10
   
3. Sort by total score
4. Return top 10 results
```

### Geocoding Fallback:
```javascript
If no results in database:
1. Try OpenWeatherMap geocoding API
2. Try 5 different query variations
3. Prioritize Indian results
4. Return up to 5 matches
```
