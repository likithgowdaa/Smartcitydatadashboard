## 🔍 Search Features

### Smart Search Prioritization:
```
1. Exact match (highest priority)
2. Starts with query
3. Contains query
4. Priority 0.5 (Bangalore) ranked first
5. Priority 1 (Karnataka) ranked second
6. Priority 2 (India) ranked third
7. Priority 3 (World) ranked last
```

### Location Name Variations Supported:
```
✓ Old & New Names (e.g., Mysore = Mysuru)
✓ Common Misspellings
✓ Alternative Names (e.g., Calicut = Kozhikode)
✓ Abbreviations (e.g., Trichy = Tiruchirappalli)
```

### Geocoding Fallback:
```
If location not in database:
1. Try original query
2. Try city name only
3. Try with country code
4. Try without spaces
5. Try first word only

Prioritizes Indian results when multiple matches found
```
